## Build notes (interpretation, not transcript)

Five phases. Contact Agent Gray, Machine side. Enemies: Exiles (phase 1, maybe phase 2) and imposter Agents (phases 2 and 4). Friendly Exile, friendly Machine Agents, friendly Zion operatives plus Morpheus.

Random names: retail gave the Exile, the two Agents and the six guards a random name per run. For our build, pick one name per NPC (for example run A's: Connor Higley, Agent Brown, Agent West, Draw, Apollo, Locust, Quail, Rat, Fabre) and put it into the lines that name them (entries 12, 14, 22, 26, 35 and the objective texts). Morpheus is fixed. Gray's "Ms. Napilitano" is the player's character name: use the player-name token if we have one, else drop the name ("Impressive work, operative.").
