- briefing: Flood 7:57:29 (entry 2).
- enter: Operator "This place is wall to wall with Zion operatives; I don't think they'll be happy to see you here."
- enemies: Zion (Binary, Zion Ravager, Zion Network Attacker); a group, count not visible.
- goals:
  1. Loot "Card" from a Zion hostile's body (Binary is the only named hostile; best guess). Objective text suggestion: "Get the Card". On loot: Operator "That Card should give you access to the Zion network on site."
  2. Use the Computer (needs Card): retail text "Search the Zion network for information on Morpheus' murder". Operator line when near/at it: "The computer on the Zion network is in this room. We'll need access to the network before we can search their system files." On use: Operator "I think you just pissed them off." then "You've got company!" (an ambush spawns: Zion Ravager / Zion Network Attacker).
  3. Search Computer for "Recording": retail text "Take the Recording from the Computer" (waits for 2; possibly also for the ambush to die - Operator says "Search the computer!" ~2 minutes after "You've got company!"). On done: Operator "Take a hardcopy of that." then "That recording must be what the Merovingian is looking for." Computer text: "Access Codes accepted! / Permission granted. / Data file "Morpheus_045.recording" has been downloaded to the disk in Drive A."
- end: exit (not captured, presumably "Goals for this area are complete. Find the nearest exit quickly!").
