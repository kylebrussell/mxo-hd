## Build notes (interpretation)
Story: E Pluribus Neo are using a map stolen from the Merovingian to sabotage Machine power lines (8.2.2's maps). The Merovingian questions Veil, and sends the player to raid Danielle Wright's company for something to use against EPN; the computers there show that Wright had Zionites steal Persephone's old pod code from the Merovingian. The Merovingian has a dire lupine, Binomi, carry a doctored copy of that code to EPN; the player gets him to their boss and has him killed so that EPN take the code, whose modified link will let the General's Sentinels track the EPN hovercraft for the Machines.
