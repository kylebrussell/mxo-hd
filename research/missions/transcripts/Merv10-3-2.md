## Build notes (interpretation)

The FTP server drops the connection, so the player finds the server, powers it back up from the mainframe and takes the file as Agents arrive; at another office's terminal the passwords start to work until Machines close in; and at the next try Agent Pace is waiting with a warning to stop.
