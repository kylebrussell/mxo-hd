# Shared mission open-floor resolver (isolated foundation)

This branch currently adds a pure resolver and source evidence only. Nothing calls it from normal staging, mission admission, persistence, UI, views or object interaction. Runtime integration is held until measured-model/default-pose and complete nearby-static coverage are reviewed. Missing OSID coverage is not treated as empty space or invalid NAV.

The core is `MissionOpenFloorResolver.TryResolve(Request, out Result)`. Inputs are immutable: raw source identity/pose; separately audited native anchor/quaternion/evidence; target GOID and measured default-pose model min/max; actual usable-range profile; finite same-floor NAV surfaces and normal standing root; existing site bounds; and a world-scoped measured-static snapshot with horizontal/vertical coverage and explicit completeness. Known modeled sources require a matching measured source obstacle. Invisible markers require positive NoModel evidence. Instance identities distinguish game objects from other props; no CSV key precedence is invented.

The base rests at `NAV floor - separately proven supportMinY`. Outward-rounded conservative envelope min/max remain separate from the exact support height, so rounding does not introduce an object lift. Interaction HalfExtents are separate from rendered geometry. The complete rotated model bounding footprint must fit a flat convex NAV polygon and existing site bounds and avoid every relevant closed static bound. Static exclusion uses Minkowski expansion and deterministic convex-cell subtraction. The numerical separation is derived from f32 coordinate ULP and the existing geometric epsilon; it is recorded, is not an avatar margin or search radius, and final published/cast footprints are rechecked. No source static is hidden, moved, bound or deleted.

Standing-space cells subtract the source, all other relevant measured static footprints and the resolved proxy. A fixed shared-edge route from the explicit normal root must reach a standing point that passes the unchanged native interaction lower-bound predicate. Route clearance conservatively projects statics whose vertical extent intersects the floor-to-standing segment; no avatar width, head volume, animation sweep, LOS, native collision, physical walking or picking claim follows. Final cast route points and range are checked again.

Results are deterministic for identical inputs, with anchor-distance, source-surface and coordinate tie ordering. Floating analytic symmetries need not pick a particular face; input/obstacle order and cyclic polygon start are canonicalized and regression tested. No grid, seed search, 400-unit displacement cap or alternate site selection exists. The finite candidate/cell policy can conservatively return NoPlan rather than claim complete packing feasibility.

`ValidateFixed` requires the saved input fingerprint and validates a fixed pose/path without rerunning nearest-centre choice. `ValidateSet` rejects same-phase overlap and cross-blocked approaches without repacking. Runtime code must preserve the immutable raw source separately, persist fixed results and fingerprints, and use one effective pose everywhere. Those hooks and schema migration are not implemented here.
