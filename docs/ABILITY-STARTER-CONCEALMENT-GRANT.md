# Starter Concealment grant rank

Concealment (503) grants 1137 through a while-loaded function-2 modifier with no separate endpoints or scale. The existing function-2 value rule uses the learned parent rank. The grant has a level cap of 50 and uses the same qualified data shape as the Sneak grant.

PR410's stock capture `3ef3dc4c8f4c:542` shows the early rank-zero `80 b2 71 04 00 00 08 02`. Actions did not list 1137. The pair now uses the loaded grant registry at world readiness, which publishes both the child base record and its ranked `80 bc 45` source relation. Unloading or reloading 503 removes or restores both records. With character level 19 and Concealment trained to 18, the granted 1137 applies Stealth +18. [PR410](https://github.com/kylebrussell/mxo-hd/pull/410).

Use `ability-parity-starter-concealment-rank` to find one Concealment in Actions at login. Unload and reload 503 normally, then select Rifles and activate Concealment through Actions or a stock hotbar. Retain the actual request and the Stealth +18 record. The disposable uses the full captured Sneak request with 1137 and the live self handle substituted. Actions rendering and the exact 1137 press remain native checks.

Concealed Shot armor piercing also remains open. The shipped client loads its GOB flag into modifier byte +0x18 at 62520cc9. The tooltip paths at 621eefcc and 621e96c5 display term 0x7a00025f. The reviewed health modifier slice does not establish how this flag changes authoritative resistance inputs.
