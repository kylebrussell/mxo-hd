# Current-mission prop visibility diagnostic

This is a private-view experiment, not a placement correction or a renderer-ready claim. It leaves the selected mission, source, published OpenFloor placement, original view, statics, inventory, goals and rewards unchanged. It does not fix a height or assume why a body is invisible.

The `mission-prop-visibility` NativeQa mode seeds exactly the 20 earlier Machine receipts before Margin login. CSR110 normally calls Agent Gray, accepts Disturbing Trends (201201), talks to Ophiuchi, and uses the saved ordinary elevator doors to reach the Computer phase. There is no selected mission/progress/item seed. The headless scenario reuses the normal InteriorAdmissionProof route and stationary exact-arrival receipt/first-body evidence, stopping before Take. It discloses its route-position aids; a wire creation is not proof of native drawing.

`MXO_MISSION_PROP_QA=1`, dev commands, a strictly named disposable mxotest schema, CSR110, a current living world owner, and the actual phase1 free GO3 object1 are all required. Other modes default the feature off. The original must still own the same mission/progress identity, Started, phase, object/entity, placement/source hash, state, world/life/transport epoch, and original view/spawn. Phase/owner/reset/state changes invalidate the observation and private lease. A private copy never enters the mission object dictionary. Same-key controls copy presentation data only, and have no object/loot authority.

The original creation observer records actual Position, Orientation, CurrentState, MissionKey, UseCount and encoded creation, plus selected source, model support-floor and actual NAV-plane height. It does not identify the architectural IPRF or prove that its floor is the rendered floor. A marker parent must not be treated as architecture. No global offset follows from these measurements.

## One native pass before Take

Use the actual mode-produced original; never select a source, site or old coordinate. Keep the camera fixed, move the avatar clear, and record original drawing or NO DRAW and the original trace fields. Before interacting with the original:

1. `?missionprop zero 3 0`: late GO3 at the exact original position/quaternion/state/use count, zero key.
2. `?missionprop same 3 0`: same exact pose, literal original mission key. This replaces only the previous private copy. Record drawing or NO DRAW for both.
3. With the same camera compare `?missionprop <zero|same> <3|548|552> <0|25|50|75|95|100>`. Each command owns at most one private lease. GO3 delta0 preserves all position bytes. Box/Safe delta0 puts their measured support minimum on `originalCentreY - 25.00377655029297`; their own measured minima are -40 and -50. Deltas change Y only. No HalfExtents, resource, original/static or mission mutation occurs.
4. A clone's normal Actions/use may yield generic zero-item loot, never the Map Disk, mission goal, payout or receipt. `?missionprop off` removes only the private lease. Clear it before Take on the real mission object.

Record all negative observations rather than retrying sources or adjusting geometry. The historical PR230 static-NAV1600 GO3 at centreY1625.003776550293 drew at delta0; the earlier native height-failure conclusion was retracted. The later native204 source0d100166 was reported invisible, including cold relog, at centreY1225.00377655/standingY1295. Those are different producers/sites and establish no universal +95 correction. The diagnostic intentionally captures its own current source and pose instead of forcing either case.
