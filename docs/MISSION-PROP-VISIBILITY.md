This is a private-view experiment, not a placement correction or a renderer-ready claim. It leaves the selected mission, source, published OpenFloor placement, original view, statics, inventory, goals and rewards unchanged. It does not fix a height or assume why a body is invisible.

The `mission-prop-visibility` NativeQa mode seeds exactly the 20 earlier Machine receipts before Margin login. `MXO_MISSION_PROP_QA=1`, dev commands, a strictly named disposable mxotest schema, CSR110, a current living world owner, and the actual phase1 free GO3 object1 are all required. Other modes default the feature off. The original must still own the same mission/progress identity, Started, phase, object/entity, placement/source hash, state, world/life/transport epoch, and original view/spawn. Phase/owner/reset/state changes invalidate the observation and private lease. A private copy never enters the mission object dictionary. Same-key controls copy presentation data only, and have no object/loot authority.

The original creation observer records actual Position, Orientation, CurrentState, MissionKey, UseCount and encoded creation, plus selected source, model support-floor and actual NAV-plane height. It does not identify the architectural IPRF or prove that its floor is the rendered floor. A marker parent must not be treated as architecture. No global offset follows from these measurements.
