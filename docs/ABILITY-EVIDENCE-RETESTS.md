This review compares the executable audit with base `a1847468` after the rifle opener package merged. It covers 41 PRs and 47 issue comments, including the later PR329 native result. The [audit method](ABILITY-AUDIT.md) requires executable and test evidence for every identified behavior plus a stock-client representative in the row's family. A result can close a specific check while the row remains partial.

## Running the three fixtures

Run one mode per disposable profile. In the stock client, only CSR_Tester (110) is selected. The helper characters enter via the existing headless harness.

```powershell
dotnet build tools/NativeQa -c Release
dotnet tools/NativeQa/bin/Release/net8.0/NativeQa.dll --bootstrap-checks "<repository>" "<proof-directory>" ability-evidence-timed-buffs ability-evidence-direct-heals ability-evidence-pet-repairs
```

- **Timed buffs:** Stay at the seeded spot. Record the Status add/removal frames and affected stats. Cast Efficiency (321) and compare the next ability's actual IS debit. Let Firearms Skill (124) expire; dismiss the long-lived effects in the stock Status panel. For Bolster or Upgrade Health, compare fresh own-vital records or a readable maximum. The headless fixture covers the consumer math separately from what the Status panel displays.
- **Direct heals:** Select QAFriend, 2 m away and below maximum. Keep the default style and +20% seeded healing influence. Use Actions for 80, 413, 234, 235, 414 and 513, waiting for the appropriate reuse timer. Expected unclipped deltas are 15, 84, 24, 57, 91 and 15. An ordinary heal publishes a recipient HP update and separate Heal/Healed log lines. Natural regeneration can update the same bar between casts.
- **Owned-pet repairs:** Summon Remote Proxy 5.0 (594), select it through the Simulacra window and cast Fortify (20). The level-50 Fortify adds 750 to maximum while current HP stays put. Without changing the caster loadout, record a fresh HP/effect update for each ordinary cast. Expected deltas are 20, 34, 117, 174 and 83. Verify a player selection does not repair the pet, recording whether the stock client suppresses the cast or the server refuses it. No hostile attack or synthetic pet wound is needed.

The headless replays verify exact wire records and serialize measured results to the proof directory. Native run instructions are available with `--fixture-plan <mode>`.
