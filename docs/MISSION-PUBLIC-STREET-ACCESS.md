This package adds a separate audited original outdoor-access layer. Fresh world1 interior-content stages require a reciprocal original outdoor-network component, a counted public opening and an own-GO native door, then an existing validated interior path to the lobby. It is not an all-world navigation or collision proof. Doorless openings without positive original open semantics remain refused.

A public door response keeps the original static key and raw CSV record, selects its original native GO before creation, and uses its measured pose. Ordinary public Open never rides to a mission floor. Request output is tied to the captured client/world/life/transport lifetime. Malformed recognized street data quarantines the owned mission after item restoration. Ordinary bound/furniture stages use a source-choice carrier without manufacturing an NPC or free-object witness.
