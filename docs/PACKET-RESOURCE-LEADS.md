## Intake Rules

1. Ask for raw text packet logs and context notes, not screenshots or summaries.
2. Do not accept account passwords, private keys, client binaries, or unrelated asset archives into the tracked corpus.
3. Run `scripts/triage-packet-capture.sh --source <path> --out <triage.md>` before importing.
4. Preview with `scripts/import-packet-capture.sh --source <path> --label <lead> --sender <sender> --provenance <source> --context <notes> --dry-run`.
5. Import only reviewed text-like packet logs, then regenerate `docs/generated/packet-research-summary.md` and `.json` with `scripts/packet-research.sh`.
