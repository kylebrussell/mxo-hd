# Audit cosmetic rows: gameplay effect or metadata

This review covers the 14 rows that the ability audit marked `cosmetic`. For each row it decides from the shipped 7.6005 data whether there is a gameplay effect the server must implement. The sources are `gameobjects.pkb` (GOB SHA-256 `3e47f11012f6f219a26c9f5decfa10cbc00726c397937d03c3068254e5424103`), the shipped Python under `research/client-scripts`, and read-only string searches of `client.dll` (SHA-256 `cb5ffcc6bb046fc01e9b10cd8e0c5aa86a82ce8a6a50549c0af6b5c55f79cf3a`). The GOB sweep reads all 44,406 templates with `research/abilities/extract_catalog.py extract(..., raw_goids=True)`. It checks every integer field that stores one of these rows' ability GOIDs and every string field that names a callback.

## Server behavior and tests

The six metadata rows and the two record-only rows need no new server code. `CosmeticRowResolutionTests` pins that state:

- `MetadataOnlyRowsAuthorNoModifierGrantCallbackOrExecutor`: loading any of 18, 397, 537, 538, 539 or 1199 changes no stat that the catalog can name. Each row has no modifier, grant, aura, buff, temp-mod, pet, utility, test, script or tool executor.
- `CoderDisciplineDoesNotReachTheShippedCoderApplicationCraftingBonuses`: loading Coder leaves every crafting total unchanged.
- `ResistInfectionPublishesOnly1055AndLeavesEveryDebuffRadiusUnchanged`: the only change is 1055 +25. The radius of 333, 38, 60 and 97 stays the same, and 177 stays at 0. The earlier `AbilityPassiveTests.DirectDebuffRadiusUsesCaster177WhileUnproven75LinkStaysExcluded` covers the same boundary.
- `UncannySensesPublishesOnlySneakAttackDetectionAtItsRankCap` and `SneakOpenerAdmissionIgnoresTheTargetsSneakAttackDetection`: the only change is 577 +40. Detection 204 does not change. The Suplex and Diving Frankensteiner rear admissions succeed against the same target whether or not it has 161 loaded.

The blocked rows stay `cosmetic`. Their server text names the missing system. Code Shaper needs both an aura executor and an incoming viral path to player simulacra before its row can close. The tapping rows need a sourced tapping executor. Cryptography and Repair Items have no reachable shipped target.
